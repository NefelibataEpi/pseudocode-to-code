# Pseudocode to Code

This repository is used to practice turning pseudocode into real code.

The focus is on understanding both:

- Algorithms (process and logic)
- Data Structures (internal implementation)

---

## What this repo contains

- Algorithm implementations
- Data structure implementations
- Practice based on pseudocode
- Some notes when necessary
